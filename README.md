# Simple_contact_managment_system

The Simple Contact Management System is a CRUD-based application developed to organize and manage contact information effectively. The system allows users to add new contacts with essential details, display all stored contacts, search contacts by name or phone number, update existing contact information, and delete contacts when no longer required.
This project helps in understanding core programming concepts such as data storage, input validation, control structures, and modular design. It is suitable for beginners and demonstrates real-world application of basic software development principles.

🔹 Key Features 
- Add new contacts
- View all saved contacts
-  Search contacts by name or number
- Update contact details
- Delete contacts
- Simple and user-friendly interface
